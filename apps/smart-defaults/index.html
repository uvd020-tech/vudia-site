Smart Defaults

Pre-fill the Jira Create dialog with default values for each project and issue type.

Set default values for the Jira Create dialog per project and issue type: priority, assignee, labels, components, versions, dates, description templates and custom fields, with dynamic values like {today+7} and {currentUser}.
